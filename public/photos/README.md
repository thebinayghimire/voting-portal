# Voting Symbol Image Download Guide

Use this folder for the voting symbol images shown on the voting page.

Instructions:

1. Download an image for the symbol listed in the `Download this symbol` column.
2. Save or export the image as a JPG file.
3. Rename it exactly as shown in the `save_name_as` column.
4. Put the renamed file inside this folder: `public/photos`.

Important:

- The voting page loads images using this pattern: `public/photos/<candidate_id>.jpg`.
- If the downloaded file is PNG, WEBP, or SVG, convert/export it to JPG before using the filename below.
- Keep each image square if possible so all voting cards look consistent.
- `Sambhav Aryal` has no symbol listed in `tableConvert.com_dxpbr8.md` or `candidates.json`, so no image filename is included for that candidate yet.
